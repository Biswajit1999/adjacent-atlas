Map what science can do next.

Adjacent Atlas combines public code activity and literature signals to rank research methods, instruments and concepts near a field’s working frontier. The shipped reference graph focuses on extreme-precision radial-velocity instrumentation.

Status: early development. The engine and data schemas are usable; the live fetch pipeline remains the active edge.

Evidence inputs

Public code and literature signals are normalised into explicit, source-linked graph records.

Transparent ranking

Every adjacency score exposes its momentum, recency, connectivity, novelty and feasibility components.

Scientific scope

The reference atlas examines EPRV instrumentation; the schemas and engine are designed for additional domains.

Current heuristic

adjacency = 100 × (0.30·momentum + 0.20·recency + 0.20·connectivity + 0.15·novelty + 0.15·feasibility)

This is an interpretable prioritisation heuristic—not a trained predictor and not a claim of scientific importance. Illustrative seed values are identified in the methodology documentation.
